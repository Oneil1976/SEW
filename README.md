# SEW
SEW Inverters - tools for testing  
Controll box for testing Inverters  
  -  8 Switches to Inverter Digital IN
  -  1 Switch for Break Release
  -  8 LED diodes for presenting of Digital OUT from inverter
  -  2x Potenciometers for Analog In to the converter
